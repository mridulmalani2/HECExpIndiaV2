## Prompt for Replit Agent:

**Task: Add a hover effect to image cards that reveals the full image when users hover over them, especially useful for movie posters in the Bollywood section.**

Please implement the following hover effect solution exactly as provided:

**Step 1:** Open the file `src/index.css` and add the following CSS code at the end of the file (after all existing styles):

```css
/* Hover Effect for Image Cards - Drop-in Solution */
.hover-reveal-card {
  position: relative;
  overflow: hidden;
}

.hover-reveal-card .card-image-wrapper {
  position: relative;
  width: 100%;
  height: 16rem; /* h-64 in Tailwind = 256px */
  overflow: hidden;
  background: #1a1a1a;
}

.hover-reveal-card img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  transition: all 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

/* Hover state with 400ms delay */
.hover-reveal-card:hover img {
  /* Delay before effect starts */
  transition-delay: 400ms;
  /* Switch to contain to show full image */
  object-fit: contain !important;
  /* Slight scale down to indicate interaction */
  transform: scale(0.95);
  /* Add subtle shadow for depth */
  filter: drop-shadow(0 10px 20px rgba(0,0,0,0.3));
}

/* Optional: Special treatment for Bollywood section */
[data-section-id="bollywood"] .hover-reveal-card:hover img,
.bollywood-card:hover img {
  /* Bollywood posters get full reveal */
  object-fit: contain !important;
  background: #0a0a0a;
}

/* Smooth exit transition (no delay on mouse leave) */
.hover-reveal-card:not(:hover) img {
  transition-delay: 0ms;
}

/* Optional: Add a subtle overlay that appears on hover */
.hover-reveal-card::after {
  content: '';
  position: absolute;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background: linear-gradient(180deg, 
    transparent 0%, 
    transparent 70%, 
    rgba(0,0,0,0.7) 100%
  );
  opacity: 0;
  transition: opacity 300ms ease;
  transition-delay: 400ms;
  pointer-events: none;
  z-index: 1;
}

.hover-reveal-card:hover::after {
  opacity: 1;
}

/* Keep text content above overlay */
.hover-reveal-card .card-content {
  position: relative;
  z-index: 2;
}
```

**Step 2:** Open the file `src/components/Card.tsx` and modify the Card component structure. Find the main card div element and add the class `hover-reveal-card` to it. Then wrap the img element in a div with class `card-image-wrapper`. Also add the class `card-content` to the div containing the text content. 

The structure should look like this:
- The main card div should have the class `hover-reveal-card` added to its existing classes
- The img element should be wrapped in a `<div className="card-image-wrapper">`
- The div containing the title and description should have the class `card-content` added to its existing classes

**What this achieves:**
This creates a smooth hover effect where images that are cropped (like movie posters showing only partial faces or titles) will reveal their full content when users hover over them. The effect has a 400ms delay to prevent accidental triggers when users are just moving their mouse across the page. The image transitions from cropped (object-cover) to full view (object-contain) with a subtle scale animation. This is particularly useful for the Bollywood section where movie posters need to show both the title and actors' faces clearly.
